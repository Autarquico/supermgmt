# ADR-0002: UUIDv7 identifiers

- Status: Accepted
- Spec: §6.3

## Decision

All internal identifiers are UUIDv7 generated with `github.com/google/uuid` (`NewV7`), stored and transmitted as lowercase canonical text. Mutable names are never primary keys; human references resolve to IDs before execution.

## Consequences

IDs sort by creation time, which keeps SQLite B-tree inserts mostly append-only and makes event and job listings naturally ordered. The creation time is visible in the ID; IDs are not secrets and must never be used as credentials (tokens are separate high-entropy random values, §9).
