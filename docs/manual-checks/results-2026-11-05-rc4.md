# Manual check results: v0.1.0-rc.4, 2026-11-05

First run of the real-host and real-account checklists. Rows not listed here were not run. A row marked "partial" passed what it could observe and names what it could not. Defects are numbered (D1, D2, ...) and filed as issues; checklist errors found on the way are corrected in the checklists themselves.

## Environment

- SuperMgmt `v0.1.0-rc.4` (commit `9a1ecd8`), local mode on macOS (darwin/arm64), and as a `proxmox-lxc` appliance. Section 7 of m3-real-pve also used builds of `main` at `fd98fb1`.
- Proxmox VE 9.1.1 (`pve-manager/9.1.1/42db4a6cf33dac83`, kernel 6.17.2-1-pve), one node, Debian 13.
- Lab nodes: Debian 13 from the official cloud image (systemd 257.13, root login), Ubuntu 24.04.5 from the official cloud image (systemd 255.4, `ubuntu` admin with sudo).
- Cloudflare: a Free zone in an account with an existing Zero Trust organisation, One-time PIN as the only identity provider. `cloudflared` 2026.10.7 on the nodes (from `pkg.cloudflare.com`), 2026.10.3 on the laptop.
